# BalancePet 安装与升级

当前发布候选：`v0.7.8`；对应功能扩展：Usage Analytics `v0.2.11`（本地预览包，尚未发布）。以下版本历史保留开发过程记录。

当前版本：`v0.7.8`；对应功能扩展：Usage Analytics `v0.2.11`（本地预览包，尚未发布）。`0.3.0` 为功能版本，`0.3.1` 增加安装器与应用双语支持，`0.3.2` 修复重复启动会创建多个桌宠实例的问题，`0.3.3` 修复长时间运行后余额刷新可能卡住的问题并优化多账户名称保存；`0.4.0` 增加 AI 登录状态本地桥接和本地 API 账户自动匹配；`0.5.0` 开始提供资源型宠物扩展的安装、启用、禁用和卸载基础；`0.6.0` 增加独立进程功能扩展宿主和脱敏用量事件管道；`0.7.0` 将同一扩展的多个版本合并显示，并加入扩展独立更新检查；`0.7.1` 修复更新频率选择保存、扩大 Hook 用量字段兼容范围，并改善用量插件导航与无 Token 数据提示；`0.7.2` 统一保存行为；`0.7.3` 增加 Windows 风格的“取消/确定/应用”按钮，并让“应用”在窗口保持打开时立即刷新桌宠；`0.7.4` 尝试修复设置选项实时回显；`0.7.5` 为所有设置下拉框增加独立的只读显示同步，修复选择后必须关闭窗口才更新的问题；`0.7.6` 扩大用量字段兼容性，并合并同一任务 Start/Stop 事件的元数据，统计窗口改为无边框融合样式并增加自动刷新倒计时；`0.7.7` 从 Codex 本地 rollout 的 `token_usage_record` 中读取当前任务的脱敏 Token 与缓存计数，并写入现有用量事件管道；`0.7.8` 修复 Codex 停止钩子缺少会话身份时无法关联 Token 记录。后续仅修复问题时递增补丁号，新增向后兼容功能时递增次版本号。

## 推荐安装方式

从 GitHub Release 下载 `BalancePet-<版本>-Setup.exe`。

安装器打开后会先选择 `简体中文` 或 `English`，之后的安装页面会按该语言显示。安装完成后，也可在桌宠的“配置接口”窗口中切换应用语言。

安装器会先让用户选择安装范围：

- **仅为当前用户安装（推荐）**：默认位置为 `%LOCALAPPDATA%\Programs\BalancePet`。不需要管理员权限，程序内检查更新会直接替换该目录中的程序文件。
- **为此设备所有用户安装**：默认位置为 `C:\Program Files\BalancePet`。安装和后续程序内更新需要用户确认 Windows UAC。

两个模式都可以在安装器目录页中改为其他位置或文件夹名称。后续使用同一安装器升级时，会沿用先前选择的安装目录。安装器会创建开始菜单入口、可选的桌面快捷方式和卸载入口。

应用程序本身始终以普通用户权限运行。即使安装到 `Program Files`，每个 Windows 用户的配置、DPAPI 加密令牌、缓存和用量记录仍保存在自己的 `%LOCALAPPDATA%\BalancePet` 目录，互不共享。

## 程序内检查更新

1. 从托盘菜单选择“检查更新”，阅读更新说明后确认。
2. 程序会下载 GitHub Release 资产并校验 SHA-256。
3. 如果当前安装目录可写，程序下载 ZIP、等待自身退出、原地替换文件并重启。
4. 如果目录不可写，例如 `Program Files`，程序下载 `Setup.exe` 并启动安装器。用户确认 UAC 后，安装器会关闭正在使用的程序文件、替换文件，并在安装完成页提供启动新版程序的选项。
5. 取消 UAC 或取消安装器不会修改当前版本。

每个余额账户可选择关闭自动刷新、30 秒、1/5/15/30 分钟、1 小时或自定义秒数（最少 30）；例如填写 300 表示 5 分钟。关闭后该账户不产生后台轮询。桌宠手动刷新不受自动间隔设置影响，但两次手动刷新至少间隔 5 秒，不会在短时间内连续重复请求。

开机启动启用时，新版本首次启动会将 Windows 启动项更新为当前 `BalancePet.Wpf.exe` 路径。安装目录保持不变，版本号只存在于程序、Release 标签和下载文件名中。

## 从旧版 ZIP 迁移

旧版 ZIP 用户可以直接安装新的 `Setup.exe`。已有配置和令牌不需要迁移，因为它们一直保存在 `%LOCALAPPDATA%\BalancePet`。

安装完成后启动新版程序一次，确认接口、托盘图标和桌宠工作正常。若此前启用了开机启动，新程序会把当前用户的启动项改为新的安装路径；确认无误后可以手动删除旧 ZIP 解压目录。

Claude、Qwen、Gemini 等客户端 Hook 如果仍使用旧目录下的 `tools` 脚本，需要在新版安装目录中重新运行 `tools\install-balancepet-client-hooks.ps1`，或在客户端配置中改为新路径。安装器不会静默修改这些客户端配置。

## 便携 ZIP

`BalancePet-<版本>-win-x64.zip` 可以解压到任何当前用户可写的稳定目录中使用，适合不需要开始菜单和卸载入口的场景。不要将 ZIP 解压到带版本号的临时目录后反复更换目录；程序内更新会覆盖当前目录，不会为每个版本创建或重命名安装文件夹。

ZIP 用户若选择了受保护目录，程序内更新会要求使用同版本的 `Setup.exe` 进行管理员安装。配置和令牌不会放在程序目录中，也不会被安装器或更新器删除。

扩展 ZIP 位于主程序目录旁的 `extension-library` 文件夹，设置窗口的“在线插件库”会列出主仓库 `plugin-catalog.json` 中登记的可用扩展；目录只用于发现，点击安装后仍会下载、校验 SHA-256，并走本地 manifest/ZIP 安全校验。网络不可用时使用最近一次有效缓存，也可以继续手动导入本地 ZIP。设置窗口会将同一扩展的多个版本合并成一个条目，并在行内提供安装/卸载、启用/禁用、更新和启动图标。升级主程序不会覆盖扩展；卸载只删除已安装的运行副本，不会删除扩展库 ZIP，因此可以随时重新安装。扩展更新检查可在高级设置中单独选择每次启动、每天、每周或仅手动；扩展通过 manifest 的 `update_url` 声明自己的 GitHub Release 地址。若主程序安装在 `Program Files` 等受保护目录，建议直接把 ZIP 放入该文件夹，或使用便携版/当前用户安装模式以便程序写入扩展库。扩展包损坏或不兼容时不会安装。资源扩展规范和制作工具见 [docs/extension-spec/v1/README.md](extension-spec/v1/README.md)，功能扩展规范和插件目录格式见 [docs/extension-spec/feature-v1/README.md](extension-spec/feature-v1/README.md)。

跨 Windows 用户或跨电脑迁移时，请在设置窗口导出设置，再在新环境导入。导出文件不包含访问令牌；令牌受 Windows DPAPI 保护，不能直接复制到其他用户或电脑使用，需要重新填写。
