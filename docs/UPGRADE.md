# BalancePet 升级说明

1. 从旧版本托盘菜单选择“退出”，确认旧进程已经结束。
2. 将新版本压缩包解压到新的文件夹，不要覆盖正在运行的旧目录。
3. 启动新目录中的 `BalancePet.Wpf.exe` 一次。
4. 确认接口、托盘图标和桌宠工作正常后，可以删除旧程序文件夹。

配置、加密令牌和用量记录保存在 `%LOCALAPPDATA%\BalancePet`，升级程序文件不会删除这些数据。开机启动已启用时，新版本首次启动会自动把 Windows 启动项迁移到当前可执行文件。

跨 Windows 用户或跨电脑迁移时，请在设置窗口导出设置，再在新环境导入。导出文件不包含访问令牌；令牌受 Windows DPAPI 保护，不能直接复制到其他用户或电脑使用，需要重新填写。
