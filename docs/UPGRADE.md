# BalancePet 安装与升级

当前正式版本：`v1.0.0`；上一正式版：`v0.9.1`。对应扩展：Usage Analytics `v0.3.3`、Notification Center `v0.5.15`、BalancePet Mica `v1.0.0`，三者均通过独立仓库 Release 分发。以下版本历史保留开发过程记录。

`v1.0.0` 包含 `v0.9.1` 之后的功能扩展：独立用量统计与逐条使用记录、消息中心与脱敏实时状态、New API 服务端用量日志同步、多账户状态与扩展安装/更新管理，以及 Mica 主题扩展。后续仅修复问题时递增补丁号，新增向后兼容功能时递增次版本号。

## 推荐安装方式

从 GitHub Release 下载 `BalancePet-<版本>-Setup.exe`。

安装器打开后会先选择 `简体中文` 或 `English`，之后的安装页面会按该语言显示。安装完成后，也可在桌宠的“配置接口”窗口中切换应用语言。

安装器会先让用户选择安装范围：

- **仅为当前用户安装（推荐）**：默认位置为 `%LOCALAPPDATA%\Programs\BalancePet`。不需要管理员权限，程序内检查更新会直接替换该目录中的程序文件。
- **为此设备所有用户安装**：默认位置为 `C:\Program Files\BalancePet`。安装和后续程序内更新需要用户确认 Windows UAC。

两个模式都可以在安装器目录页中改为其他位置或文件夹名称。后续使用同一安装器升级时，会沿用先前选择的安装目录。安装器会创建开始菜单入口、可选的桌面快捷方式和卸载入口。

应用程序本身始终以普通用户权限运行。即使安装到 `Program Files`，每个 Windows 用户的配置、DPAPI 加密令牌、缓存和用量记录仍保存在自己的 `%LOCALAPPDATA%\BalancePet` 目录，互不共享。

## 程序内检查更新

1. 从托盘菜单选择“检查更新”，阅读更新说明后确认。
2. 程序会下载 GitHub Release 资产并校验 SHA-256。
3. 如果当前安装目录可写，程序下载 ZIP、等待自身退出、原地替换文件并重启。
4. 如果目录不可写，例如 `Program Files`，程序下载 `Setup.exe` 并启动安装器。用户确认 UAC 后，安装器会关闭正在使用的程序文件、替换文件，并在安装完成页提供启动新版程序的选项。
5. 取消 UAC 或取消安装器不会修改当前版本。

每个余额账户可选择关闭自动刷新、30 秒、1/5/15/30 分钟、1 小时或自定义秒数（最少 30）；例如填写 300 表示 5 分钟。关闭后该账户不产生后台轮询。桌宠手动刷新不受自动间隔设置影响，但两次手动刷新至少间隔 5 秒，不会在短时间内连续重复请求。

开机启动启用时，新版本首次启动会将 Windows 启动项更新为当前 `BalancePet.Wpf.exe` 路径。安装目录保持不变，版本号只存在于程序、Release 标签和下载文件名中。

## 从旧版 ZIP 迁移

旧版 ZIP 用户可以直接安装新的 `Setup.exe`。已有配置和令牌不需要迁移，因为它们一直保存在 `%LOCALAPPDATA%\BalancePet`。

安装完成后启动新版程序一次，确认接口、托盘图标和桌宠工作正常。若此前启用了开机启动，新程序会把当前用户的启动项改为新的安装路径；确认无误后可以手动删除旧 ZIP 解压目录。

Claude、Qwen、Gemini 等客户端 Hook 如果仍使用旧目录下的 `tools` 脚本，需要在新版安装目录中重新运行 `tools\install-balancepet-client-hooks.ps1`，或在客户端配置中改为新路径。安装器不会静默修改这些客户端配置。

DeepSeek Harness 的桥接插件同样是复制进 DSH profile 的，升级 BalancePet 不会更新 profile 里的那份副本。在“AI 联动”页勾选 DeepSeek Harness 后保存会自动刷新它；也可以手动运行 `tools\install-balancepet-dsh-plugin.ps1`，它会先删掉旧副本再复制，并保证 `cordis.patch.yml` 里始终只有一条挂载项。用 `-Action Status` 可以只查看当前状态而不改动任何文件。

## 设置项重组（0.2.x 起）

原先只有一个“自动跟随 AI 任务”开关，它同时管着 Codex、Gemini CLI、Qwen Code、Claude Code 和自定义 CLI。现在每个客户端一个开关，统一放在新的“AI 联动”页；“桌宠与交互”页的“功能开关”更名为“交互开关”（只剩音效、气泡、互动动作、动效、彩蛋）；“随 Windows 启动”移到“高级与迁移”。

设置文件会自动从 schema 3 迁移到 4：原来“自动跟随 AI 任务”为开时，五个 Hook 客户端会一并展开为开，**行为与升级前完全一致**；DeepSeek Harness 的开关保持各人自己设过的值不变。

同一版本移除了“系统通知”开关及其托盘气泡功能 —— 每次 AI 任务结束时弹出的 Windows 气泡会正好盖住右下角的桌宠。该功能移除后，事件记录仍然保留在消息中心扩展里，只是不再弹窗打扰。

## 便携 ZIP

`BalancePet-<版本>-win-x64.zip` 可以解压到任何当前用户可写的稳定目录中使用，适合不需要开始菜单和卸载入口的场景。不要将 ZIP 解压到带版本号的临时目录后反复更换目录；程序内更新会覆盖当前目录，不会为每个版本创建或重命名安装文件夹。

ZIP 用户若选择了受保护目录，程序内更新会要求使用同版本的 `Setup.exe` 进行管理员安装。配置和令牌不会放在程序目录中，也不会被安装器或更新器删除。

扩展 ZIP 位于主程序目录旁的 `extension-library` 文件夹，设置窗口的“在线插件库”会列出主仓库 `plugin-catalog.json` 中登记的可用扩展；目录只用于发现，点击安装后仍会下载、校验 SHA-256，并走本地 manifest/ZIP 安全校验。网络不可用时使用最近一次有效缓存，也可以继续手动导入本地 ZIP。设置窗口会将同一扩展的多个版本合并成一个条目，并在行内提供安装/卸载、启用/禁用、更新和启动图标。升级主程序不会覆盖扩展；卸载只删除已安装的运行副本，不会删除扩展库 ZIP，因此可以随时重新安装。扩展更新检查可在高级设置中单独选择每次启动、每天、每周或仅手动；扩展通过 manifest 的 `update_url` 声明自己的 GitHub Release 地址。若主程序安装在 `Program Files` 等受保护目录，建议直接把 ZIP 放入该文件夹，或使用便携版/当前用户安装模式以便程序写入扩展库。扩展包损坏或不兼容时不会安装。资源扩展规范和制作工具见 [docs/extension-spec/v1/README.md](extension-spec/v1/README.md)，功能扩展规范和插件目录格式见 [docs/extension-spec/feature-v1/README.md](extension-spec/feature-v1/README.md)。

跨 Windows 用户或跨电脑迁移时，请在设置窗口导出设置，再在新环境导入。导出文件不包含访问令牌；令牌受 Windows DPAPI 保护，不能直接复制到其他用户或电脑使用，需要重新填写。


## CC Switch 联动已移除（1.2.23 起）

主程序不再读取 CC Switch 的当前账户。此前它会在检测到账户变化时自动切换桌宠显示的账户，并弹出一条登录状态气泡；这个行为与手动选择账户互相干扰，且状态轮询会让同一条气泡反复出现。

移除的内容：`CCSwitchAccountBridge`、`CCSwitchBridgeStatus`、`AiAccountActivity`、`AccountSourceClassifier`，以及设置窗口里的「读取 CC Switch 当前账户」开关。设置文件里遗留的 `cc_switch_integration` 键会被自动忽略，不需要手动清理。

**账户切换现在只由你决定**：托盘或右键菜单，以及新增账户时的自动切换。

消息中心的契约没有变化：主程序仍然发布 `login_known` / `login_mode` / `login_detail` 三个字段，但固定为空值，扩展会回退到它自己记录的历史登录事件。将来以插件形式重新提供 CC Switch 联动时，这几个字段就是现成的接入点。


## 1.2.24 修子

1.2.23 在移除 CC Switch 联动时误删了设置窗口的两行初始化代码（第 88 行和第 1508 行是超长行，其中同时包含 CCS 复选框和其他几十个赋值，整行删除导致所有开关在界面上显示为未勾选）。设置文件本身没有被破坏，但若在 1.2.23 里点过「确定」或「应用」，会把默认值写入。1.2.24 已恢复这两行，请勿使用 1.2.23。


## 形象改为安装包（1.4.0 起）

形象不再全部随安装包分发。1.4.0 把其中十二套改为可安装的形象包；**1.4.3 把最后两套——DeepSeek 小鲸鱼「澜汐」和 ChatGPT 小白龙「霁珑」——也移了出去**。至此主程序只自带一套内置占位形象。

对升级用户的影响依次是：

1. **形象不会丢，也不用重新下载。** 安装目录里原有的形象文件夹会由主程序在启动时转换成已安装的形象包，正在使用的形象保持不变。这是升级路径的全部意义：安装器只会添加和覆盖文件，所以旧形象本来就在那里，转换只是把它们纳入管理。
2. **全新安装只有占位形象。** 其余形象在「扩展 → 在线插件库 → 形象」分类里自行下载。安装过程中不再有任何形象下载。
3. **占位形象不可卸载，也不出现在在线目录里。** 它是唯一保证存在的形象——桌宠就是窗口本身，没有形象可画时窗口会是一片空白，也没有界面可以退回。

形象的九状态素材、可选动画帧和台词文件都属于资源扩展包，格式见 [资源扩展规范 v1](extension-spec/v1/README.md)；在线目录与在线台词两份文档见 [形象仓库文档规范](extension-spec/appearance-v1/README.md)。

### 1.4.4：转换曾被一个完成标记阻断

1.4.2 及更早版本把 DeepSeek 与 ChatGPT 作为内置形象分发，其迁移逻辑会跳过内置形象，因而每次启动都判定「无事可做」，并把 `pet-migration.v1.done` 写入 `%LOCALAPPDATA%\BalancePet`。1.4.3 将这两套移出内置列表——这正是使它们可被转换的前提——但迁移以该标记为闸门，标记已存在便不再执行转换。

因此**如果在 1.4.3 上升级，这两套形象会停留在「能用但不是包」的状态**：窗口绘制正常，但在「形象」分类里显示为可安装而非已安装，且无法卸载、不会收到更新。该标记在 1.4.4 中整体移除，升级到 1.4.4 或更高版本后启动一次即可完成转换。标记文件本身不需要手动删除。

### 1.4.5：台词不再随美术重下

台词原先只存在于形象包内，而形象包的体积几乎全是美术：更正一个词意味着重新发包，并让每份已安装副本为了数百字节重下数兆。1.4.5 起台词另外汇总为形象仓库中的一份文档，主程序联网时优先读取它，改台词不再需要发版或下载。

已安装的 1.0.x 版本形象包**不需要**为了台词而更新，在线文档会在下次启动时为其提供各自的台词；更新到 1.1.0 的作用是让包内自带一份离线副本。
