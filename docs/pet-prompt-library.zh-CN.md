# BalancePet 形象扩充提示词库

本文件用于使用 GPT-Image-2 生成 BalancePet 的模型专属状态图。提示词选择自 GPT-Image2 Style Library 的 `character-design-sheet`（角色设定表）和 `illustration-art-style`（插画与艺术风格）方向，并按本项目现有 WPF 素材协议整理。

## 生成目标

- 每次只生成一张状态图，不要生成九宫格、精灵图或角色设定表。
- 输出 `2048x2048`、`PNG`、真正的 RGBA 透明背景。
- 一个画面只保留一个完整角色，角色完整落在画布内，四周至少保留约 8% 安全边距。
- 9 张图必须使用同一角色、同一画布、同一镜头距离、同一底部锚点和相近的角色高度。
- 参考图只用于保留发型、脸型、瞳色、服装主色、材质和核心配饰；去除参考图中的文字、Logo、水印、医疗设备、UI、场景和其他角色。
- 不要生成白底、灰底、棋盘格预览底、黑底、投影、光晕、粒子、速度线或漂浮符号。透明像素必须是 Alpha 0，而不是把棋盘格画进图片。

## 复制用主提示词

把下面整段复制到 Image 2，并附上对应的模型参考图。将尖括号中的两项替换掉：

```text
为 BalancePet 桌面宠物生成一张独立状态素材 PNG。

角色身份：<身份锁定句>
状态动作：<状态动作句>

严格以附带参考图为唯一角色身份依据，保留角色的脸型、发型、瞳色、肤色、服装主色、主要饰品、尾巴/耳朵/翅膀等识别特征；把角色缩成清晰可读的 Q 版桌宠比例。只画一个完整角色，正面或轻微三分之二视角，动作围绕身体中心展开，脚底/身体下缘固定在同一基线。表情和肢体要能一眼表达状态，但动作保持小幅、自然、适合循环播放。

构图：正方形 1:1，2048x2048，角色完整可见，四周留出安全边距，角色高度和底部锚点稳定；纯透明背景，真正 RGBA Alpha 通道。
画风：清爽的二次元 Q 版角色插画，线稿干净，色块和高光克制，缩小到桌宠尺寸后脸部和核心配饰仍清楚；保持参考图的材质和配色，不添加新服装或新道具。

禁止：白色/灰色/黑色背景、棋盘格背景、场景、地面、投影、光晕、烟雾、粒子、速度线、气泡、箭头、表情符号、文字、Logo、水印、UI、边框、九宫格、分镜、重复角色、裁切身体、额外手臂或腿、角色漂浮、角色超出画布。

只输出一张透明 PNG，不要附加说明文字，不要把文件名或状态标签画进图片。
```

## 9 个状态动作句

文件名必须严格使用下表；状态句直接替换主提示词里的 `<状态动作句>`。

| 文件名 | 状态动作句 |
| --- | --- |
| `idle.png` | 安静待机，身体轻微呼吸或轻微摆动，眼神自然，双手/肢体放松；不要挥手、奔跑、跳跃或新增道具。 |
| `loading.png` | 专注等待结果，身体略微前倾，眼睛聚焦，双手靠近身体做小幅准备动作；不要画加载图标、旋转符号或文字。 |
| `success.png` | 任务成功后的轻快开心姿势，露出自然笑容，一只手做小幅庆祝动作；不要画勾号、星星、文字或漂浮特效。 |
| `error.png` | 遇到错误后的抱歉和困惑表情，眉眼略显沮丧，双手做轻微道歉姿势；不要画红叉、警告符号、烟雾或文字。 |
| `low.png` | 余额偏低时的疲惫、担心状态，肩膀略低、表情克制但可读；不要画数字、硬币、警报或额外道具。 |
| `clicked.png` | 被点击后的短暂惊讶反应，眼睛稍微睁大，身体有轻微弹起或回头；保持角色完整，不要添加点击波纹。 |
| `codex-working.png` | AI 任务进行中，表情专注，身体略微前倾，双手保持工作姿态但不出现电脑、代码、文字或 UI。 |
| `codex-done.png` | AI 任务完成后的放松和满足，表情温和，姿态恢复稳定，可有小幅点头或轻微抬手；不要画完成图标。 |
| `inactive.png` | 长时间无操作后的安静休息，眼睛闭合或半闭，身体轻微松弛；不要睡床、枕头、场景或漂浮的 Z 字。 |

## 文件放置与验收

生成完成后先按下面的暂存目录放置，不要改变文件名；我验收通过后再复制到程序资源目录：

```text
素材/Claude/<状态文件>.png
素材/Kimi/<状态文件>.png
素材/Qwen/<状态文件>.png
```

本轮只生成：`claude`、`kimi`、`qwen`。已有完整状态图的五个目录保持不动；其他只有立绘参考图的模型暂不接入，等下一轮再处理。

每个目标目录已经有 `idle.png`，因此本轮每个模型只需要生成下面 8 个文件：

```text
loading.png
success.png
error.png
low.png
clicked.png
codex-working.png
codex-done.png
inactive.png
```

不要重新生成或覆盖 `素材/Claude/idle.png`、`素材/Kimi/idle.png`、`素材/Qwen/idle.png`，除非后续验收明确发现它不是透明 PNG。

你把每个目录缺少的 8 张 PNG 放回 `素材/<模型>/` 后，我会检查：

1. 图片是否为 RGBA、透明像素是否真的为 Alpha 0。
2. 是否全部为 2048x2048，角色高度/底部锚点是否稳定。
3. 是否有白底、棋盘格烘焙、文字、Logo、裁切或额外角色。
4. 通过检查后再解除设置窗口中的“素材尚未完成”禁用状态，并重新打包主程序。
