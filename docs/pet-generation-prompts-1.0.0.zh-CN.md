# BalancePet 1.0.0 剩余形象生成提示词
这份提示词包用于补齐当前还没有素材的 10 个形象：`ernie`、`glm`、`gpt-image2`、`llama`、`mimo`、`mistral`、`opencode`、`perplexity`、`rwkv`、`seedence`。

提示词结构采用 GPT-Image-2 Style Library 的：

- `character-design-sheet`（角色设定表）：先锁定角色身份、比例、服装、配件和动作一致性。
- `illustration-art-style`（插画与艺术风格）：使用清晰构图、材质、配色和情绪，不让模型只输出“风格词”。
- `3d-collectible-toy`（3D 收藏玩具）：只有在需要偏立体公仔感时才使用，不能改变已有二次元/插画角色的身份。

## 使用方式

先为每个形象生成一张 `idle.png` 作为唯一身份参考，再基于同一张参考图生成其余 8 个状态。不要一次要求模型生成九宫格、整张精灵图或 16 个视线方向；这些动作需要后续分别生成和验收。

项目当前状态文件固定为：

```text
idle.png
loading.png
success.png
error.png
low.png
inactive.png
clicked.png
codex-working.png
codex-done.png
```

建议输出：`2048x2048`、PNG、真正的 RGBA 透明背景。角色应占画布高度约 75%～86%，脚底/身体下缘保持同一基线，四周保留安全边距。

## 通用主提示词

把下面整段复制到 GPT-Image-2，把 `<身份锚点>` 和 `<状态动作>` 替换掉，并附上该角色的 `idle.png` 作为参考图。

```text
为 BalancePet 桌面宠物生成一张独立状态素材 PNG。

角色身份：<身份锚点>
状态动作：<状态动作>

严格以附带参考图为唯一角色身份依据。保留同一张脸、头身比例、发型或主体轮廓、主色、材质、眼睛设计、核心配件和识别性道具；不要因为状态变化而换装、换发型、换颜色或增加新的设定。角色是可长期显示在桌面上的小型 Q 版 AI 助手，单个完整角色居中，正面或轻微三分之二视角，动作围绕身体中心展开，脚底/身体下缘固定在同一基线。

构图与输出：正方形 1:1，2048x2048，PNG，真正 RGBA Alpha 透明背景；角色完整可见，不能裁切，四周保留约 8% 安全边距；镜头距离、角色高度、底部锚点与参考图一致；缩小到桌宠尺寸后，脸部、眼睛和核心配件仍然清楚。

画风：清爽、干净、可读性优先的 Q 版角色插画，参考图的线稿、材质和光影逻辑保持一致；色块简洁，高光克制，边缘清晰，不要把角色画成海报、场景插画或复杂概念设定图。

状态表达：只通过表情、眼神、手脚/翅膀/耳朵/尾巴、身体重心和小幅动作表达状态；动作自然、适合循环播放，不要用文字或图标代替表演。

严格禁止：白色、灰色、黑色或棋盘格背景；场景、地面、投影、光晕、烟雾、粒子、速度线、气泡、箭头、表情符号、文字、Logo、水印、UI、边框、九宫格、分镜、重复角色、额外手臂或腿、裁切身体、漂浮角色、透明区域被画成棋盘格。不要复制任何平台官方 Logo、商标、界面截图或可读文字。

只输出一张透明 PNG，不要附加说明文字，不要把文件名或状态名称画进图片。
```

## 统一状态动作句

将下表的句子粘贴到通用主提示词的 `<状态动作>`。

| 文件名 | 状态动作 |
| --- | --- |
| `idle.png` | 安静待机，身体只有轻微呼吸、眨眼或材质摆动，眼神自然，肢体放松；不要挥手、奔跑、跳跃或新增道具。 |
| `loading.png` | 专注等待结果，身体略微前倾，眼睛聚焦，核心配件有轻微准备动作；不要画加载图标、旋转符号、进度条或文字。 |
| `success.png` | 任务成功后的轻快开心姿势，露出自然笑容，一只肢体做小幅庆祝动作；不要画勾号、星星、礼花或漂浮特效。 |
| `error.png` | 遇到错误后的抱歉和困惑表情，眉眼略显沮丧，双手/前肢做轻微道歉姿势；不要画红叉、警告符号、烟雾或文字。 |
| `low.png` | 余额偏低时的疲惫、担心状态，肩膀或主体略低，表情克制但可读；不要画数字、硬币、警报或额外道具。 |
| `inactive.png` | 长时间无操作后的安静休息，眼睛闭合或半闭，身体轻微松弛；不要画床、枕头、场景或漂浮的 Z 字。 |
| `clicked.png` | 被点击后的短暂惊讶反应，眼睛稍微睁大，身体轻微弹起或回头；不要添加点击波纹或 UI。 |
| `codex-working.png` | AI 任务进行中，表情专注，身体略微前倾，手/前肢保持工作姿态；不要出现电脑、代码、文字或 UI。 |
| `codex-done.png` | AI 任务完成后的放松和满足，表情温和，姿态恢复稳定，可有轻微点头或抬手；不要画完成图标。 |

## 生成顺序与验收

建议按下面顺序逐个完成，先做身份最容易稳定的角色，再做材质和结构更特殊的角色：

1. `llama` → `mimo` → `rwkv` → `glm`
2. `perplexity` → `seedence` → `mistral`
3. `ernie` → `opencode` → `gpt-image2`

每个形象都要经历：

1. `idle.png` 身份确认：确认脸、轮廓、主色、核心配件和底部锚点。
2. 生成剩余 8 个状态：每次只生成一张图，并附同一张 `idle.png` 参考图。
3. 生成 16 个视线方向时，先生成 `000`、`090`、`180`、`270` 四个基准方向，再按 22.5° 连续插值；不要直接旋转整只角色或只移动新画的眼珠。
4. 检查透明度：必须是 RGBA，透明像素 Alpha 为 0；不能是白底、棋盘格或烘焙阴影。
5. 检查桌宠尺寸：缩小后仍能认出角色，状态动作一眼可读，角色没有跳基线、裁切或漂浮。

状态图最终放入对应目录：

```text
versions/csharp-wpf/assets/pets/<id>/<state>.png
```

本文件只负责提示词，不会自动修改或覆盖程序素材。素材通过视觉验收后，再接入程序并重新打包。
