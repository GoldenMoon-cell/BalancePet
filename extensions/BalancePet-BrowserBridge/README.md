# BalancePet Browser Bridge

当前版本：1.0.0

这是 BalancePet 的本地浏览器桥接扩展，用于让主程序读取已登录中转站的会话，而不需要手动复制 Cookie。本仓库是独立发布仓库；主程序在线插件库会将它标记为“浏览器扩展”，只提供仓库入口，不会尝试把它安装成主程序功能扩展。

## 使用

1. 在 Edge 或 Chrome 打开 `edge://extensions` 或 `chrome://extensions`。
2. 打开“开发人员模式”。
3. 选择“加载已解压的扩展”，选择本目录。
4. 在 BalancePet 设置中打开“高级：从本机浏览器读取会话”。
5. 点击“通过浏览器扩展连接”，记下 6 位配对码。
6. 切换到已经登录中转站的浏览器标签页，点击扩展图标并输入配对码。
7. 点击“同步当前站点会话”。

更新扩展后请先在扩展管理页重新加载扩展，再回到中转站用量页面按 `Ctrl+R` 刷新一次；页面捕获器需要在页面加载早期安装。同步成功提示中应显示“页面捕获器 已安装”，并列出捕获到的用量响应数量。首次同步成功后，扩展会在配对码有效期间每 30 秒向本机增量同步新用量响应；主程序设置窗口关闭时也会继续接收。

扩展只申请当前标签页站点的 Cookie 权限；如果站点没有 Cookie，也会尝试读取当前页面中常见的网页会话键。数据通过 `127.0.0.1` 发送给本机 BalancePet，不经过公网。配对码首次有效期为 10 分钟；每次自动同步成功都会续期 10 分钟。只要浏览器页面仍登录且扩展能正常同步，就不需要重新输入配对码。连续 10 分钟无法同步（例如 Cookie 失效、页面关闭或账号退出）后才会失效。
