# Changelog

## 0.5.15

- 新增脱敏实时状态快照，环绕层优先显示当前余额、任务状态和 CC Switch 登录状态，不再依赖启动时的历史通知。
- 主程序余额刷新、任务开始/结束和账户切换会立即更新环绕层；历史通知仍保留给消息列表和旧版本回退。

## 0.5.14

- 修复安装包中的窗口图标未作为 WPF 资源嵌入，导致消息中心启动时立即崩溃的问题。

## 0.5.13

- 修复桌宠镜像到窗口左侧后，鼠标悬停并按住 `Shift` 无法展示环绕信息的问题。
- 触发区域会同步桌宠的镜像方向和缩放比例，并缓存配置文件状态以避免频繁读取磁盘。

## 0.5.12

- 移除多余的手动刷新按钮，消息列表继续通过本地文件变化自动更新。
- 补齐窗口应用图标，并按 Windows 11 / Windows 10 自动调整窗口圆角。

## 0.4.0

- 插件运行时接管主程序气泡展示，避免原生大气泡与插件气泡重复出现。
- 插件退出后主程序自动恢复原生气泡，无需修改设置。

## 0.3.2

- 移除通知卡片、类别标题、时间和进度条样式，改为带尾巴的桌宠对话气泡。
- 启动新版插件时自动结束扩展目录中遗留的旧版消息中心进程。

## 0.3.1

- 将拆分消息改为桌宠左侧的三层紧凑气泡，不再覆盖桌宠形象。
- 标题、数值与说明依次进入并同时驻留，随后再依次退出。
- 气泡跟随桌宠窗口移动，三个固定位置不会因后续气泡加入而跳动。

## 0.3.0

- 新增独立浮动消息气泡，不修改主程序原有单气泡逻辑。
- 将每条脱敏消息拆分为标题、数值、说明，按顺序淡入、停留并淡出。
- 插件启动后自动监听新的本地消息事件，历史消息不会在启动时重复播放。
- 关闭消息中心面板后继续后台监听，禁用或卸载扩展时再停止。

## 0.2.0

- 使用与 BalancePet 一致的 Fluent 风格、自定义标题栏和紧凑信息层级。
- 自动跟随 Windows 应用浅色或深色模式。
- 增加胶囊式分类筛选、消息类别色标和完整空状态。
- 隐藏底部完整数据路径，保留简洁的本地只读隐私提示。

## 0.1.0

- 首个预览版：按类别查看气泡摘要。
- 支持读取主程序的 NDJSON 事件流与轮转文件。
## 0.4.1

- 安装后自动启用并后台运行，不再需要单独点击“启动”。
- 刷新进度、`--` 占位值和桌宠彩蛋不再进入新气泡。
## 0.5.0

- 移除自动弹出的新气泡。
- 鼠标停在桌宠上并按住 `Shift` 时，围绕桌宠依次显示最近消息。
- 改为无底色文字和短横线分隔，不再使用气泡边框、尾巴或进度卡片。
- 松开 `Shift` 或移开鼠标后按顺序淡出。
## 0.5.1

- 修复按住 `Shift` 时信息只显示片刻便消失的问题。
- 消息内容未变化时不再反复重建展示；按住期间持续显示到松键或鼠标移开。

## 0.5.2

- 按每条信息所在的桌面背景区域计算相对亮度，自动选择高对比的浅色或深色文字。
- 为文字增加与前景相反的轻描边，并同步调整短横线颜色，改善复杂壁纸上的可读性。
- 显示期间周期性重新取样，桌宠移动或壁纸背景变化后会自动更新配色。

## 0.5.3

- 将背景取样改为每次展示前执行一次，显示期间不再持续读取屏幕像素或刷新阴影，降低按住 `Shift` 时的卡顿。

## 0.5.4

- 根据桌宠所在显示器的工作区动态选择环绕槽位，靠近右侧或底部时自动把内容迁移到仍有空间的方向。
- 环绕窗口改为随实际槽位收缩，避免固定窗口在屏幕边缘裁切右侧信息。
- 配合 BalancePet 1.0.0-dev.30，将余额刷新相关反馈保留在主程序原生气泡中。

## 0.5.5

- 将固定方向槽位改为自由角度椭圆环绕布局，可在桌宠周围任意角度寻找可见位置。
- 边缘避让时优先保留各信息原来的相对位置，并使用缓动动画滑向新位置，不再瞬间跳动。
- 展示层固定在当前显示器工作区，避免窗口原点变化抵消信息移动动画。

## 0.5.6

- 环绕布局改为整体角度覆盖：桌宠位于屏幕中央时形成完整轨道，靠近边缘时形成连续可见扇形。
- 屏幕边缘不再把信息退化为上下两排；各信息仍沿桌宠中心的椭圆轨迹分布。
- 同时求解五条信息的角度和避碰关系，保留平滑移动并避免互相遮挡。

## 0.5.7

- 按信息矩形与桌宠边界计算最小轨道距离，常规位置仅保留 4px 安全缝，减少无意义空白。
- 只有发生信息互相遮挡时才将个别条目向外错层，边缘场景仍保持连续扇形环绕。
- 环绕层仅展示余额、进行中的任务、账户状态和交互模式；刷新过程、本次消耗和其他临时反馈继续使用主程序原生气泡。

## 0.5.8

- 信息位置改为按可见弧线等角度分布，中央接近四等分环绕，边缘保持规律扇形。
- 信息与桌宠的最小间距按矩形边界计算，只有发生碰撞时才沿原角度向外错层。
- 信息块高度收紧至 48px，去掉字体和下划线之间的弹性空白，下划线与详情文字保持 4px 间距。

## 0.5.9

- 桌宠处于屏幕四角时使用确定性的半包围布局，四条信息沿面向屏幕内部的统一椭圆弧线排列。
- 角落布局采用统一半径和等分弧线，避免单条信息被独立向外推远后产生异常大空位。
- 四个角分别镜像同一组布局参数，保持一致的间距、方向与动态过渡。

## 0.5.10

- 环绕信息固定为四个状态槽：余额、当前登录方式、任务状态和当前版本。
- 余额槽合并“账户余额 / 上次余额 / 本次消耗”，显示最近发生的一种状态。
- 登录槽合并官方账户、官方 API 和 CC Switch 登录事件，统一显示当前登录来源。
- 任务槽合并工作中与已停止状态，随最新任务事件切换；版本槽直接读取正在运行的主程序版本。

## 0.5.11

- 修正余额槽的聚合语义：分别取得账户余额、上次余额和本次消耗的最新有效记录，并在同一个信息块中同时显示。
- 忽略空数值和 `--` 占位值；某一类数据尚不存在时只显示已有余额信息。
