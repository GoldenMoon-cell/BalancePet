# BalancePet Electron

This is a historical Electron implementation kept for reference. It owns the renderer UI and keeps provider credentials in the Electron main process with Windows secure storage. The continuing implementation is the C# WPF version in `versions/csharp-wpf`.

Current migration surface: generic balance API settings, DPAPI-backed token storage, balance bubbles, sound feedback, DeepSeek/ChatGPT image selection, free-drag/locked interaction modes, and Codex process state notifications.
